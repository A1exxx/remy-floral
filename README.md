# Remy Boutique Floral — лендинг-визитка

Статический сайт для цветочного бутика Remy (Алматы). Гость сканирует QR
на мероприятии → попадает сюда → заказывает букет в WhatsApp.

**Живой адрес:** https://a1exxx.github.io/remy-floral/

Без сборки и зависимостей: HTML + CSS + один файл JS. Деплой — обычный
`git push`, ломаться нечему.

---

## Как поменять то, что меняется чаще всего

### Телефон, адрес, часы

Всё в одном месте — `js/app.js`, объект `CONTACT` в начале файла.
Продублировано в разметке (футер, JSON-LD) — искать по номеру.

```js
var CONTACT = {
  waPhone: '77056666163',      // wa.me — только цифры, без «+»
  phoneTel: '+77056666163',
  phoneDisplay: '+7 705 666 61 63',
  ...
};
```

> Номер подтверждён карточкой 2ГИС и bio Instagram. Если меняете —
> проверьте, что на новом номере **есть WhatsApp**: это главная кнопка сайта.

### Фото букетов

1. Положите новые файлы в `assets/bouquets/` как `tile-XX.avif` + `tile-XX.webp`
   (квадрат, 420×420) и `tile-XX-lqip.webp` (20×20 — размытая заглушка).
2. Пропишите их в массиве `GALLERY` в `js/app.js` — `id`, `cls`, `alt`.

Проще: положите оригиналы рядом и прогоните `python tools/prepare_tiles.py`.

**Про `alt`:** пишите, что реально на фото («букет из синей гортензии с
жёлтыми розами»), а не «фото букета». Это и для незрячих, и для поиска.

### Города и политика доставки

Массив `CITIES` в `js/app.js`. У каждого города `mode`:

- `own` — доставляем сами (сейчас только Алматы);
- `ask` — подтверждаем возможность и срок вручную.

От `mode` зависит подпись под селектором, текст кнопки и шаблон сообщения
в WhatsApp. Появилась реальная доставка в Астану — поменяйте её `mode` на
`own`, больше ничего править не надо.

### Тексты

Всё в `index.html` обычным текстом. Шаблоны сообщений для WhatsApp — в
`js/app.js`, объект `TPL`.

> После правки текстов прогоните `python tools/subset_fonts.py` — шрифты
> урезаны под используемые символы, новая буква иначе отвалится в системный
> шрифт. Весь русский и латинский алфавит уже в запасе, так что это нужно
> только для необычных символов.

## QR-коды

Лежат в `qr/`, по одному на место размещения:

| Файл | Куда клеить | Метка |
|---|---|---|
| `qr-vitrina.png` | витрина / вход | `?s=vitrina` |
| `qr-stol.png` | коктейльные столы | `?s=stol` |
| `qr-upakovka.png` | упаковка, карточка в букете | `?s=upakovka` |
| `qr-banner.png` | фотозона, баннер | `?s=banner` |

Метка уезжает во **все** сообщения WhatsApp строкой `Источник: vitrina` —
так видно, какая точка реально приносит заказы, без всякой аналитики.

Перегенерировать: `python tools/make_qr.py`.

**Печать.** Коррекция ошибок H (30%), проверено — читаются вплоть до 1.5 см.
Рекомендую всё же 2.5–3 см и обязательно проверить на трёх разных телефонах
перед тиражом. Тихое поле вокруг кода не обрезать.

## Что ещё не подключено

**Форма листа ожидания.** Пока `FORM_ENDPOINT` в `js/app.js` пустой, форма
не делает вид, что заявка ушла, — она открывает WhatsApp с уже вписанным
контактом. Заведёте Google Форму или Tally — вставьте URL в `FORM_ENDPOINT`,
форма начнёт слать туда.

**Аналитика.** В `js/app.js` есть функция `goal()`, она уже вызывается на
всех кнопках (`wa_order`, `wa_star`, `call_click`, `city_almaty`,
`city_other`, `waitlist_submit`). Останется вставить счётчик Яндекс.Метрики
и прописать `YM_ID`.

**Свой домен.** `remyfloral.kz` куплен, но на момент сборки DNS не отвечал.
Когда поднимется: четыре A-записи GitHub Pages (`185.199.108.153`,
`185.199.109.153`, `185.199.110.153`, `185.199.111.153`), файл `CNAME` в
корне репозитория с одной строкой `remyfloral.kz`, затем в настройках Pages
дождаться сертификата и включить Enforce HTTPS.

> Написание `remy_floral.kz` невозможно: подчёркивание запрещено в имени
> хоста (RFC 952/1123), публичные CA с 2019 года не выпускают на такие
> имена сертификат, и KazNIC такое имя не зарегистрирует.

## Инструменты

Разовые скрипты, для работы сайта не нужны — нужны, чтобы пересобрать ассеты.

| Скрипт | Что делает |
|---|---|
| `fetch_bouquets.py` | качает кадры из Instagram (ссылки подписанные, истекают) |
| `prepare_tiles.py` | режет их в тайлы: снимает вожжённые цены и лица, AVIF + WebP |
| `trace_logo.py` | вордмарк из превью CorelDRAW в SVG |
| `fetch_fonts.py` | забирает PT Serif и Inter с Google Fonts локально |
| `subset_fonts.py` | урезает шрифты под используемые символы (547 → 72 КБ) |
| `make_brand_assets.py` | og:image, favicon, apple-touch-icon |
| `make_qr.py` | брендированные QR |
| `shoot.py` | скриншоты и проверки через Chrome DevTools Protocol |

Локальный просмотр:

```bash
python -m http.server 8985 --directory D:\remy-floral
```

## Известные ограничения

- **Фото — стоп-кадры Reels 640×640**, не студийная съёмка. Верхние 26%
  срезаны, чтобы убрать вожжённые цены и лица. Галерея специально собрана
  так, чтобы средний исходник не бросался в глаза: разноразмерная мозаика,
  бордовый подвал на всех плитках, общий слой зерна, тонкая кромка. Придут
  нормальные фото — замена занимает минуты.
- **Логотип трассирован** из превью 470×256 внутри `.cdr`, потому что
  конвертера CorelDRAW в системе нет. Кривые чистые, но если у клиента есть
  исходный SVG/AI/EPS — лучше положить его вместо `assets/logo-remy.svg`.
- **`tile-11`** — витрина бутика, в кадре видны люди. Остальные семь без
  узнаваемых лиц.
